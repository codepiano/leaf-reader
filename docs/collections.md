# 合集与书架整理

本次按开发模式交付，继续使用 `npm run dev:desktop`，不生成新发布包。

## 使用方式

打开一本 EPUB 后，右上角“合集模式”会列出目录树和建议的子书起点。默认只展示第一层，点击箭头逐级展开，下级选项按需生成；折叠不取消勾选，父级显示下级已选数量。用户可以修改勾选项，再按“转为合集模式”。同一分组与它的内部章节不能同时作为起点；至少需要两个起点。起点之前的内容自动保留为“卷首内容”。

这是逻辑拆分：原 EPUB 保持原样，子书共享资源，各有自己的目录、进度、收藏、分组、标签和最近阅读时间。书架默认将子书作为单本展示，侧栏“合集”可筛选同一来源的子书。阅读目录按“合集 → 子书 → 章节”组织，保留 EPUB 3 span / 文本分组以及 EPUB 2 NCX 无 content 的分组标题；summary 支持键盘操作，折叠状态按书保存。

在“合集设置”中选择“恢复整本阅读”，即可恢复普通阅读。整本与子书进度分别保存，关闭合集模式不会抹掉子书进度与整理信息；相同边界重新启用时恢复旧进度。重新划分时，边界发生变化的子书重新计进度，避免把旧位置套用到新内容。

书卡右下角星号用于收藏，“···”用于分组和标签。侧栏提供最近阅读、收藏、分组、合集和标签筛选；书架搜索匹配书名、作者、合集名和标签。最近阅读只显示实际打开过的条目，整理和收藏操作不使未读书出现在最近阅读中。普通书与子书的整理信息互相独立。

## 数据与边界

继续使用 `library.json`，为旧记录补充默认值，保留已有进度。书架不再因超过 24 本而删除条目。合集设置、元数据和进度在同一原子替换写入中保存，写入失败时不替换内存状态。标签去重，名称限制 1–64 字符，每本最多 30 个标签。

只读取 ZIP 索引和当前章节。开启合集时按需要读取边界章节，校验锚点及顺序；共享一个 XHTML 文件的子书按 DOM 范围裁剪显示，不跨过边界，也不会把前一本书的标题带到后一本。文件起点的锚点会归一化，避免生成空白尾章。原 EPUB 不被复制或重写。

当前按有序、UTF-8 的流式 EPUB 处理。锚点边界需要有效 XHTML；找不到起点或出现重复、父子重叠选择时明确报错，不静默划分。源文件移走或原书目录被外部修改后，应重新打开、检查划分。没有推断作者、封面或物理导出子书功能。

## 选择器折叠改进

选择状态独立于已渲染的复选框保存，转换会包含尚未展开或已经折叠的已选项；重新打开弹窗默认重新折叠。支持 Enter / Space 展开按钮和原生复选框操作，无链接分组仍可见。大目录测试使用 10,020 个候选，初始仅挂载 20 个第一层选项，展开一个分组后仅追加其直接子项。

在隔离 worktree、独立依赖/输出、1438 origin 与临时 mock 数据下，Chromium 和 WebKit 各 24 组回归通过，前端构建与 TypeScript 检查通过。桌面 1180×800、900×700 检查默认折叠、逐级展开、焦点和勾选提示；未测试移动端。Rust 划分与持久化逻辑未改动，验证期间在线 dev 进程保持不变。

## 批量选择

合集选择器提供“全选当前层”和“取消全选”，工具栏明确显示当前层。展开分组后当前层是该分组的直接下级，收起后回到父层；更改复选框也可切换当前层。全选仅选择当前层可阅读节点，跳过不可用项，并移除与这些节点冲突的父级或后代勾选；其他分支保留。取消全选清空整个选择集合，包括尚未展开或已折叠的项。

批量修改会同步计数、所有已挂载的复选框、下级已选提示和转换按钮；不会为了全选创建未展开的子项。选择少于两个起点时，转换仍保持禁用。空选择时“取消全选”禁用，没有可选项的当前层“全选当前层”禁用。

在独立 worktree、独立依赖/构建输出、1438 origin 和临时数据下验证。Chromium、WebKit 各 26 组回归覆盖当前层切换、父子冲突移除、其他分支保留、折叠项清空、禁用节点、按需挂载、键盘批量操作、选择计数和实际提交的起点 ID。键盘焦点改进后，两种浏览器各补测 7 组相关回归。前端构建与 TypeScript 检查通过；桌面 1180×800、900×700 检查批量按钮、当前层提示、焦点及禁用状态，未测试移动端。Rust 划分算法与持久化未变更。
