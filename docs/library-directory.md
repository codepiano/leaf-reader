# 书库目录和可选导入

默认直接读取原文件。用户在“书库设置”中主动开启“导入到书库”并指定已存在的目录后，通过书架打开、打开按钮或拖拽打开的 EPUB 才复制到目标目录。选择导入目录本身不会扫描。扫描来源目录由独立“扫描目录”入口管理。文件已在目标目录、阅读中的子书切换及内置示例不会触发复制；关闭开关后直接读取原路径，已有副本不删除。

复制前校验 EPUB，按固定缓冲流式复制，保留原文件。同名同内容复用副本，同名不同内容加序号，使用排他创建保证不覆盖已有文件。复制失败删除本次未完成文件并报错；不会悄悄回退成另一种模式。已在目标目录及其子目录中的文件直接读取。目标目录外的符号链接同名目标不会被跟随覆盖。

导入已读原文件到尚未登记的副本路径时，迁移书架记录及对应进度、合集、元数据，原文件不移动。目标路径已有记录时以目标记录为准。目录切换不批量迁移旧文件。目录不可用时仍可从书架读取其他原路径的书。

验证在独立工作树完成，独立依赖、Cargo 输出、临时文件和回环端口 1438；在线 dev 1437 的进程在验证期间保持不变。12 个 Rust 测试通过（另 1 个 fixture 导出器忽略）；新增测试覆盖默认不复制、只设目录不复制、同名复用/重命名、原文件不变、记录迁移、非法书籍及目录消失。Chromium 和 WebKit 的 8 组测试通过，设置窗口检查桌面和 900×700 窄桌面下的长路径、焦点、禁用控件、取消选择、设置持久化与失败报错。浏览器目录选择和 IPC 为 mock，文件复制及持久化由原生 Rust 测试验证，未操作个人书库进行测试。
