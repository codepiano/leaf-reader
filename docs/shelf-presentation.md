# 封面与书架展示

先加载书籍列表，书卡进入视口附近后异步读取 EPUB 内嵌封面。前端最多同时请求两张，离开视口较远后移除图片 src，避免长期保留所有已解码图片。使用独立于阅读会话的本地资源路径，不把图片 Base64 混入书架 JSON。资源按书架记录 ID 查找，只读取该书的 EPUB；压缩包资源有 8 MiB 大小限制，封面提取失败静默保留文字封面。

识别 EPUB 3 cover-image、EPUB 2 cover 元数据、guide 封面页里的 img / SVG image，以及常见 cover 标识。支持 JPEG、PNG、GIF、WebP、SVG；不下载网络封面。自定义资源响应保留 CSP 与 nosniff，封面成功响应可由 WebView 短暂缓存。合集子书展示共享原书封面，不推断子书独立封面。

未手动分类的书首次打开进入“在读”，手动选择的“未读 / 在读 / 读过”不会在下一次打开时被覆盖。旧记录按是否打开过推断分类显示；扫描不会标记为在读。置顶与阅读分类、收藏、分组、标签独立存储，合集子书也独立保存。置顶在当前筛选结果中优先显示，收藏与置顶在封面上显示角标。

书架工具栏提供缩小、大小滑杆及放大按钮，范围 140–240 像素，默认 160，支持方向键、Home / End；到端点后禁用对应按钮，本地存储记住偏好。文字封面缩放时保持固定比例，图片加载不会改变书卡尺寸。顶部移除宣传横幅，工具栏高度改为 64 像素，书籍列表更靠上。

## 验证

所有验证在独立工作树，依赖、Cargo 输出与在线 dev 分离，浏览器使用 1438 端口和新存储。验证期间在线 Vite 和 Rust 进程保持原样，没有操作个人书籍或分类记录。

20 个 Rust 测试通过（另 1 个 fixture 导出器默认忽略），包含 EPUB 2 / 3 / guide 封面、空封面、非法/外部路径、超限资源、源文件不变，以及分类和置顶持久化、手动选择不被打开行为覆盖、子书独立状态。封面 fixture 使用进程与原子序号隔离并行临时文件。

Chromium 与 WebKit 各 19 组全量回归通过；最后的封面尺寸样式修正后，两种浏览器又分别通过 5 组相关回归。覆盖列表先出现、延迟封面、损坏图片回退、100 本书按视口请求与移除离屏 src、分类、收藏角标、置顶顺序、尺寸端点、重启保留大小、紧凑页头、原有扫描/阅读/逻辑合集功能。TypeScript、隔离前端构建、Clippy 通过。

桌面 1180×800 和 900×700 实际检查小/大书卡、文字和真实 SVG 封面、大小滑杆焦点与端点禁用、长分组下拉框、分类下拉框与收藏/置顶角标。浏览器 IPC 和封面资源路由使用 mock，封面像素来自仓库合成 EPUB；ZIP 解析和记录持久化由 Rust 测试验证。未测试移动端，也没有把浏览器验证当作新的原生启动速度或内存测量。
