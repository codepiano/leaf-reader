# 阅读位置与时长

“书库设置”分别提供位置记忆及阅读计时开关，默认开启，旧配置自动补齐默认值。开关变更立即对当前书生效。关闭位置记忆不改写已保存位置，重新打开返回开头；重新开启可恢复旧进度。关闭计时停止采集和累计，不清空历史。

前端每秒取样，只累计前台、有焦点且显示正文、没有模态弹窗的短间隔；超过 2 秒的挂起间隔丢弃，避免把电脑休眠计入。采样不会每秒写盘：默认每 15 秒，以及位置保存、失焦、可见性变化、正常离开阅读及关闭时提交。本机异常断电或强制退出可能丢失最后未提交的短时段，不声称精确到秒的屏幕注视统计。

后端按会话 token 校验，拒绝过期会话和异常大时长；关闭计时时即使收到请求也不累计。独立键保存普通书及子书时长。合集总信息汇总该来源的阅读时间，子书信息只展示该子书累计；恢复整本、切换导入路径不会主动清空历史。全部记录保存在本地 library.json，原子替换持久化。

原生隔离测试 14 个通过（另 1 个导出器默认忽略），覆盖旧配置、关闭/重开位置记忆、保留旧进度、停止计时、过期会话、异常时长、子书独立累计和导入记录迁移。TypeScript、隔离前端构建和 Clippy 通过。Chromium 与 WebKit 各 12 组回归通过，包括真实正文前台计时、当前书即时停表、虚拟时钟的前后台/暂停/禁用/挂起间隔、图书信息、书库设置及原有合集功能。

开发和验证在独立工作树完成，物理隔离依赖和 Cargo 输出，浏览器使用端口 1438、新 origin 与临时数据；测试期间在线 dev 的 Vite 及原生进程保持不变。桌面 1180×800、900×700 检查长目录、信息窗口、焦点、禁用与开关状态；长信息窗口可滚动。浏览器文件选择与 IPC 使用 mock，复制和持久化逻辑由 Rust 测试验证，没有测试写入个人书库。未测试移动端。
