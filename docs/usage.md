# Leaf 使用说明

## 打开与扫描

“打开书籍”选择 EPUB、MOBI、AZW3、PDF、CBZ、HTML、单文件 Markdown 或 TXT，也可把文件拖入窗口。“打开目录”用于将 Markdown 文件夹整本打开。也可以在侧栏“扫描目录”添加多个来源文件夹，按“保存并扫描”递归发现支持的书籍。“仅保存”只保存目录配置，稍后再扫描。

来源与书库是两套独立目录：扫描负责索引原文件；“书库设置”中的导入目录负责保存副本。导入默认关闭，主动开启并保存后，打开书架中的书或通过打开/拖拽开始阅读时才复制。扫描阶段不会复制。目标已有同名同内容副本时复用，内容不同则添加序号，不覆盖已有文件。

启动直接加载缓存，新增文件需手动重扫；移除来源不会删除书架记录或磁盘文件。目录失联、书籍损坏等错误会显示详情，其他文件仍可继续加载。单次扫描有目录项和书籍数量上限，达到上限会明确提示，可缩小目录范围后重试。详见 [扫描规则](scan-directories.md)。

## 排序与筛选

工具栏“排序”支持：

| 排序         | 规则                                     |
| ------------ | ---------------------------------------- |
| 最近阅读时间 | 最近打开的优先，未读在后                 |
| 书名         | 中文排序，数字按数值顺序处理             |
| 作者         | 作者升序，缺少作者的在后，同作者再按书名 |

所有模式都先排列置顶书，置顶组内部也遵循所选规则。排序在筛选、搜索、重启后保留；“最近阅读”只显示打开过的书，也可以使用所选排序。

侧栏可按分组、标签、收藏、阅读分类或合集筛选。搜索匹配书名、作者、合集名和标签，使用补全后的信息。星号切换收藏；↑ 切换置顶。收藏、置顶均在封面角落显示标记。

## 手动补全信息

在书卡 ⓘ 或阅读页“图书信息”中查看资料，再点“编辑信息”。支持书名、作者、出版社、出版日期、ISBN、语言、简介。出版日期和 ISBN 按文本保存，便于记录旧版、未知日期或多个标识。

输入框为空表示使用原书信息，占位文字显示原值。保存只写入本地记录，不改写原文件。修改后的书名和作者用于书架、搜索、排序、信息窗口和阅读页标题；不重置进度，不改章节标题。阅读中编辑不会重新载入正文或改变当前阅读位置。

“恢复原书信息”清空编辑框中的覆盖值，再保存生效；取消会丢弃本次未保存修改。文件已经移走时，仍能查看缓存信息和补全记录，文件大小等显示不可获取。

逻辑子书可以独立补全。子书书名留空使用原目录标题；其他空白字段继承合集公用信息。恢复子书信息不会清空父合集或其他子书的覆盖值。

## 阅读分类与整理

书卡 ··· 可设置分组、标签、阅读分类、置顶及收藏。删除分组时书籍回到未分组，保留其余信息。未手动分类的书首次打开进入在读；手动指定的未读、在读、读过不会被下一次打开覆盖。分类不等于阅读进度：可将读过的书从头重读，也可以将书保留为手动未读。

## 合集

打开合集后点“合集模式”，默认只显示第一层目录；点击箭头逐级展开，再勾选每本子书的起始目录并确认转换。折叠保留已勾选项，父级提示下级已选数量。工具栏标明当前层，展开分组或更改某一层的勾选会切换当前层；“全选当前层”选择该层可阅读的同级节点，并清除与它们冲突的父、子节点勾选，保留其他分支。“取消全选”清空所有层级，包括折叠项。支持没有链接的分组标题，使用其第一个可读子节点作为起点；首个起点之前的内容保留在“合集附加内容”入口中，不计为一本子书；原有内容和阅读记录保留。同一分组及其内部章节不能同时作为两个起点。

目录按“合集 → 子书 → 章节”折叠。子书各自保存进度、时长、分类、收藏、置顶、分组、标签和补全信息，共享原 EPUB 和封面，不生成独立文件。恢复整本阅读保留子书记录；更改划分边界可能重置相应子书进度。详见 [合集规则](collections.md)。

## 显示与阅读

阅读页工具栏的“目录”打开右侧目录。图钉亮起时目录固定在正文旁，切换章节后仍保持展开；取消固定后，目录浮在正文上，选中章节、点击正文或按 Escape 即可收起。也可用目录右上角的关闭按钮随时收起。拖动目录左边的分隔线调整宽度；用键盘聚焦分隔线后可按左右方向键调整。宽度和固定偏好会在本机保存。

工具栏“封面 − / 滑杆 / ＋”调整 140–240 像素书卡，默认 160；滑杆支持方向键、Home 和 End，端点按钮禁用。大小偏好会保留。书架先展示文字封面，附近书卡异步补上 EPUB 内嵌封面，缺失或损坏时保留文字封面。

阅读设置提供字体、字号、行距、阅读宽度及背景主题。“书库设置”可分别关闭记住阅读位置、记录阅读时长：旧记录保留；关闭记忆后重新打开从头阅读，重新开启可恢复旧位置。计时只累计前台、有焦点、显示正文的时间，弹窗与挂起不计。强制退出可能丢失最后一小段尚未保存的时长。

| 快捷键                  | 操作                   |
| ----------------------- | ---------------------- |
| ⌘ / Ctrl + O            | 打开文件              |
| ← / →                   | 上一章 / 下一章，PDF 为上一页 / 下一页 |
| Space、PageDown、PageUp | 滚动 EPUB 正文或翻 PDF 页 |
| Escape                  | 关闭当前弹窗、阅读设置或浮动目录 |

表单编辑、目录 summary 的键盘操作不触发后台翻章。

## PDF 阅读

PDF 按原页面顺序显示。输入页码后按 Enter 或点“跳转”，也可使用上一页、下一页及快捷键。PDF 内嵌目录显示在右侧目录栏，点击条目跳到对应页；没有内嵌目录时可以直接用页码。用 −、＋ 缩放，点“适合页面”将整页放入当前阅读区域。缩放后可滚动查看页面，续读时回到上次的页码。

扫描发现 PDF 时用文件名生成书架条目。首次成功打开后显示总页数。扫描版可以按原图阅读。密码保护的 PDF 暂不支持打开。

## MOBI 和 AZW3

打开或扫描无 DRM 的 `.mobi` 和 `.azw3`，从右侧目录跳转，重新打开同一本书时恢复上次位置。Leaf 在本地解包正文，按原文件路径记录阅读进度。扫描时先显示书名和作者，打开后补上章节数。

## CBZ 漫画

CBZ 按图片文件名的自然顺序阅读，例如 `2.png` 先于 `10.png`。支持 PNG、JPEG、GIF、WebP 和 AVIF；加密漫画包暂不支持。使用页码跳转、上一页和下一页翻页，使用 −、＋ 或“适合页面”调整大小。重新打开会回到上次的页码。

## Markdown、HTML、TXT 与诗歌排版

Markdown 支持 UTF-8 的 `.md` 和 `.markdown` 单文件。有「第 X 章」标题时按章阅读并保留前置内容，否则整份作为一章。相对路径图片需在文件所在目录内。开启书库复制时 Markdown 仍从原位置阅读，以免丢失图片。

Markdown 目录书按文件分章，并包含子目录。若根目录有 `SUMMARY.md`、`TOC.md` 或 `_sidebar.md`，优先按其中列出的链接排序，其余文件按自然文件名排序。这三种索引也用于扫描时识别整本目录书。支持书内相对链接及根目录内的本地图片。

支持 UTF-8 的 `.html`、`.htm`。Leaf 按自身阅读样式显示内容，从标题生成目录，保留页内链接与文件所在目录内的本地图片。不会执行网页脚本或载入远程资源。

UTF-8 的 `.txt` 按单章打开。对谈可使用 `姓名（角色）：内容` 或 `姓名(角色): 内容`。同一说话人的连续文字合并，隔开再次出现时沿用同一色标。未标注的开场和普通文本会保留。

点开正文上方的“诗歌排版”保留诗行、加大诗节间距并居中标题。此选项按书保存，可随时切回普通排版。

Markdown 渲染支持只读任务列表、带语言名称的代码高亮，以及 `$…$` 和 `$$…$$` 公式。诗歌模式会将 Markdown 章内标题加入目录。HTML 阅读时可点「HTML 原文」查看源代码。Markdown、TXT 和 HTML 的「导出 HTML」会保存当前章节，并嵌入本地图片。

## GitHub 书籍

在书架点「GitHub 书籍」，输入公开的 `https://github.com/所有者/仓库` 地址。Leaf 用系统 Git 下载默认分支并把 Markdown 文件作为一本书，优先按目录索引或根 README 的链接排序，同时保留本地相对链接和图片。重新输入相同地址并选择「检查并更新」可检查远端；有新版本且可以快进时才替换本地副本。旧章节仍存在时，续读按章节路径对齐。

## 浏览器共读

在 EPUB、Markdown、HTML 或 TXT 阅读页点击「浏览器共读」，默认浏览器会打开当前章节，页面底部可以翻章。浏览器翻章独立于 Leaf 的桌面进度。点击「结束浏览器共读」、返回书架、改读其他书籍或退出 Leaf 后，旧共读链接会失效。共读页面只在本机提供。

## 数据与备份

记录由本机 `library.json` 持久化；复制导入的书籍存在用户指定的书库目录；诗歌排版随书籍记录保存；通用排版、排序、书卡大小和目录折叠偏好保存在 WebView 中。备份书籍之外也应保存应用数据目录，恢复时保留原文件路径关系。`LEAF_DATA_DIR` 只覆盖记录路径，不改变 WebView 存储位置。

没有同步或网络抓取书籍资料功能。移走源文件或外部改写目录后，应重新打开并检查书籍与合集划分。
