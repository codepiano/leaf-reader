# 排序与手动资料补全

排序选择保存在 WebView 本地存储，默认最近阅读时间降序。书名和作者使用中文 Collator，按数值比较数字；缺少作者的条目排在作者排序末尾。所有排序都先比较置顶状态，再比较所选字段，最后用书名、作者和条目 ID 稳定处理同值。旧版秒时间戳与当前毫秒时间戳归一化后比较。筛选只改变候选集，不改变排序偏好。

手动补全按原书 / 子书 ID 单独保存。书架快照及阅读会话只解析展示名称覆盖，不在启动时额外打开所有 EPUB。信息窗口被用户打开后，才按需读取 OPF 出版社、日期、ISBN、语言和简介。原 EPUB、章节标题和阅读位置不受编辑影响。

书名、作者、出版社最多 256 字符；日期、ISBN、语言最多 64 字符；简介最多 10,000 字符。单行字段拒绝控制字符，简介允许换行。空字段表示使用来源值；子书空作者等公用字段继承合集信息，空书名使用原目录标题。“恢复原书信息”只是清空本次编辑覆盖，按保存后生效。

所有写入先验证、克隆最新书架，再原子持久化，成功后替换内存。保存失败不会更新内存中的字段。更名不改 ID、文件路径、合集边界、分组、标签、收藏、置顶和阅读分类。导入时随其他元数据迁移覆盖值。

验证在独立 worktree、独立依赖和 Cargo 输出中完成，浏览器使用 1438 origin、新上下文及合成材料，未测试写入个人书库。在线 dev 进程在验证期间保持不变。

- 22 个 Rust 测试通过，另 1 个 fixture 导出器默认忽略；覆盖原始 OPF 信息、持久化与恢复、子书独立覆盖及继承、源文件字节不变、非法输入和其他既有功能。
- Chromium 与 WebKit 各 22 组完整回归通过；覆盖三种排序、置顶优先、偏好恢复、信息编辑/取消/失败/恢复、搜索和阅读标题即时变化、正文位置不变及既有扫描/合集/阅读流程。
- TypeScript、前端隔离构建和 Clippy 通过；桌面 1180×800、900×700 检查排序下拉框、焦点、长信息输入、编辑弹窗、公共操作栏与其他表单控件；未测试移动端。
- 浏览器 IPC 为 mock，ZIP 和真实文件持久化由 Rust 测试验证；没有对当前功能重新测量原生启动或内存基线。

发布源码前检查跟踪文件和 Git 历史中的常见凭据模式，核对仅有项目测试 EPUB；忽略个人图书、运行数据、备份、环境配置与构建输出。公开仓库发布源码不等于构建新的桌面发布包。
