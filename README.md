# Leaf

安静、轻巧的本地 EPUB 阅读器。Tauri 2 + Rust，界面使用 TypeScript 和按需引入的 Web Awesome；阅读正文由系统 WebView 排版。

## 当前功能

- 打开或拖入本地 EPUB，书架长期保留条目，最近阅读独立排序。原书保留在原路径，不自动复制进书库。
- EPUB 2 NCX / EPUB 3 树形目录，保留无链接分组标题，支持键盘折叠、展开和折叠状态记忆。
- 手动切换合集模式，预览并勾选子书起点；逻辑子书共用原 EPUB，可独立阅读、收藏、分组、加标签并记录进度。同一文件内的锚点也可作为边界，不生成或改写 EPUB。
- 分组创建 / 重命名 / 删除，多标签、书籍收藏、最近阅读以及书名 / 作者 / 标签搜索。删除分组保留书籍；恢复整本模式保留子书进度与整理信息。
- 滚动阅读；按书保存章节及章内位置，重新打开恢复。书籍路径变化时需重新选择。
- 字号、行距、阅读宽度、衬线 / 无衬线字体和暖纸 / 素白 / 夜读主题。
- 内置原创示例书，可直接体验。
- `⌘/Ctrl+O` 打开，`←/→` 切章，空格 / PageDown / PageUp 滚动，Escape 关闭设置。

## 开发和构建

需要 Node.js 20.19+（或 22.12+）、Rust stable 和 [Tauri 平台依赖](https://v2.tauri.app/start/prerequisites/)。macOS 需要 Xcode Command Line Tools；Windows 需要 C++ Build Tools 和 WebView2；Linux 需要 WebKitGTK 等系统包。

```sh
npm ci
npm run dev:desktop
npm run tauri -- build
```

日常迭代使用 `npm run dev:desktop`，保持开发实例运行；前端修改由 Vite 热更新，Rust 修改由 Tauri 增量编译并重启。首次启动需要编译 Rust，后续不需要生成发布包。`npm run dev` 只启动网页预览，不提供本地 EPUB 功能。

开发窗口标题为 `Leaf Dev · 本地阅读`，应用标识为 `local.leaf.reader.dev`，阅读记录和 WebView 存储与正式版隔离。macOS 开发记录位于 `~/Library/Application Support/local.leaf.reader.dev`。开发模式的内存和启动耗时不代表发布版性能；需要性能验收或用户要求发布时再生成 release 包。测试、类型检查和验证构建继续在独立副本执行，不影响正在使用的开发实例。

macOS 的应用输出在 `src-tauri/target/release/bundle/macos/Leaf.app`。Windows / Linux 应在各自平台构建、验证。首次开发在这台 Mac 上安装了独立 Rust 工具链到 `~/Library/Caches/leaf-toolchain`，未修改 shell 配置；`scripts/tauri.mjs` 会在系统找不到 Cargo 时使用它。

## 性能设计

- 不捆绑 Chromium 或 Node.js 运行时，使用系统 WebView。
- 无 React/Vue 应用运行时；只加载按钮组件，滑块和下拉框在首次打开设置时加载。
- 启动只读取本地书架元数据，不扫描目录、解压书籍或生成封面。
- 一次只持有一本书的 ZIP 索引和一个章节的 DOM。图片、CSS、字体经受限本地协议按需解压；切章销毁旧 DOM，返回书架关闭 ZIP 文件。
- 不使用图片 base64、整书 Blob、永久资源缓存、后台索引或空闲定时轮询。
- 阅读位置变动防抖写入，切章、返回书架和关闭窗口时等待保存。

运行数据保存在 Tauri 的应用数据目录（macOS：`~/Library/Application Support/local.leaf.reader`），包括 `library.json` 和首次阅读时写入的示例 EPUB；排版设置在 WebView 本地存储。`LEAF_DATA_DIR` 可指定独立阅读记录目录，但不会改变 WebView 存储位置。已有用户实例时，QA 还应使用独立应用标识或 WebView 数据目录隔离存储。

## 验证

所有验证应在独立 checkout / 物理副本中进行，依赖、构建产物和数据都不能链接回在线服务。浏览器测试使用独立的 `127.0.0.1:1438`，开发端口是 `1437`；测试不会操作现有浏览器标签页。

```sh
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
npm exec playwright -- install chromium webkit
npm run test:ui
npm exec playwright -- test --browser=webkit
python3 scripts/benchmark.py /absolute/path/to/release/leaf-reader --runs 5 --output /tmp/leaf-benchmark.json
```

浏览器测试模拟桌面 IPC，覆盖目录、图片和样式、书内链接、进度恢复、设置持久化、控件键盘和恶意书籍内容隔离；它不能替代真实 Tauri / WebKit 验证。性能脚本启动发布二进制，等候两次动画帧后的就绪回执，记录主进程和新启动的 WebKit 辅助进程的 RSS 与物理内存；测量口径和实际验收见 `docs/verification.md`。

## 当前范围

第一版针对无 DRM 的、UTF-8 编码的流式 EPUB。未实现分页、批注、书签、全文搜索、同步及 DRM 解密。固定版式、竖排、复杂交互和混淆字体的完整还原尚未验收；混淆字体可退回系统字体。书架目前使用书名生成的封面。

正文脚本、表单、嵌入页面和外部资源不会运行。解析过程使用惰性模板，去掉外部 URL，随后用 DOMPurify 清洗；正文在不允许同源访问的 sandbox iframe 内显示；CSP 只允许应用自带的 `reader-bridge.js` 处理事件，禁止书籍脚本，正文无法访问父页面 DOM 或 IPC。资源协议仅允许当前书籍的样式、图片和字体，禁止路径逃逸，不提供任意文件读取。元数据上限 4 MiB / 100,000 XML 节点，章节上限 8 MiB，单个资源上限 32 MiB，ZIP 最多 20,000 个条目；超限时明确报错。

### 书库目录

侧栏底部“书库设置”可选择书库目录。默认关闭“导入到书库”：只读取原 EPUB。主动开启并保存后，从书架打开、新打开或拖入的 EPUB 会复制到所选书库目录，再从副本阅读，原文件不变。设置目录不会扫描、批量搬迁书架；原文件已经位于书库内时不会复制；阅读中的章节、子书切换和内置示例不触发导入。关闭导入不会删除已导入文件或记录。

同名同内容复用现有副本，同名不同内容自动添加序号。导入失败会明确报错。导入之前已阅读的原文件时，进度、合集划分、标签及收藏会随书架记录转到新路径。设置与记录保存在原有应用数据目录，不在书库中另建数据库。启动不会扫描书库或加载所有 EPUB。

### 图书信息

书卡上的 ⓘ 或阅读页“图书信息”可查看文件路径、大小、修改时间、章节数、分组、标签及收藏状态。合集子书显示所属合集、子书与原书章节数，并明确大小属于共用 EPUB。章节数按阅读内容文件计算。文件丢失时仍显示已有书籍资料和不可访问提示；查看信息不改变最近阅读时间。

### 阅读记录开关

“书库设置”中的“记住上次阅读位置”和“记录阅读时长”默认开启，可以分别关闭。关闭位置记忆后停止保存进度，重新打开从头阅读；旧进度保留，重新开启可恢复。关闭计时后立即停止累计，已有时长保留，并在图书信息中展示。普通书与合集子书分别记录时长，整本信息汇总该来源的累计时间。

计时只统计前台、有焦点且正在展示正文的时间；书架、弹窗、失焦及长时间挂起不累计。每 15 秒及切换书籍、返回书架、失焦和正常关闭时保存。强制退出可能丢失最后一小段未保存时长。全部记录仅保存在本机。

### 扫描目录与导入目录

这是两套独立设置：侧栏“扫描目录”可以添加多个来源目录（包含子目录），点击“保存并扫描”将其中的 EPUB 加载到书架；扫描只建索引、不复制文件、不标记为已读。侧栏“书库设置”中的目录是导入副本的存放位置，只有主动开启“导入到书库”后，打开书籍阅读时才复制。

扫描目录会保存，重启直接加载缓存书架；新增文件后手动重新扫描。重复/重叠目录按路径去重，读取过的书保留进度、标签和收藏；阅读时已导入的来源再次扫描不会重复建书卡。扫描单个文件失败不阻止其他书籍加载，可查看失败详情。移除扫描目录只取消后续扫描，不删除书架记录或文件。

### EPUB 内嵌封面

先展示书架，封面在书卡进入可见区域附近后异步加载，最多同时请求两张；远离视口后释放图片引用。支持 EPUB 3 cover-image、EPUB 2 cover meta 以及 guide 封面页中的内嵌图片。缺失、损坏或不支持的封面继续显示文字封面。合集子书共用来源 EPUB 的封面。封面请求不改变阅读会话和阅读记录，不扫描正文或下载网络图片。

### 阅读分类、置顶与收藏标记

侧栏“阅读分类”可筛选未读、在读、读过。首次打开未手动分类的书会进入在读；书卡“···”可手动修改分类，之后打开不会覆盖手动选择。旧记录按是否曾打开推断显示分类，扫描不会改变分类。

书卡 ↑ 可置顶或取消置顶，当前筛选结果中置顶优先，其余按最近阅读排序；“···”中也可设置置顶。收藏书的封面显示 ★ 收藏角标，置顶书另有置顶角标。普通书与合集子书独立保存这些状态。

### 书架显示大小

书架工具栏的“封面 − / 滑杆 / ＋”可即时调整书卡大小，支持键盘 Home / End 和方向键，范围 140–240 像素，默认 160。设置自动保存在本机，重启继续使用。页头使用紧凑布局，将空间留给书籍列表。
